# API Context

## Endpoint

`POST /api/ideas` is the sole backend endpoint (Architecture AD-5). There is no versioning scheme, no other routes beyond static asset serving (`GET /`, `/styles.css`, `/app.js`), and no plan to add either for this MVP.

## Request

```json
{ "prompt": "string" }
```

- `prompt`: required, string, trimmed length 1–2000 chars.

## Success Response

`200`

```json
{ "ideas": [{ "title": "string", "description": "string" }, /* exactly 3 */] }
```

- Always exactly 3 entries. The adapter (`lib/ideaService.js`) must throw rather than return anything else — see `.ai-context-errors.md`.

## Error Responses

Always `{ "error": "string" }`, with the status code carrying the meaning — never a generic `200` with an error flag inside the body.

| Code | Meaning |
| --- | --- |
| `400` | Invalid JSON body, non-string `prompt`, or trimmed `prompt` empty / over 2000 chars |
| `502` | Provider/network failure before the provider responded |
| `504` | Provider call exceeded the server-enforced timeout (25s) |
| `500` | Provider responded but output didn't parse into exactly 3 well-formed ideas, or an uncoded/unknown adapter throw |

## Breaking Change Policy

Any change to this request/response shape is an Architecture Spine amendment (a new or amended `AD-5`), not a story-level decision — update `ARCHITECTURE-SPINE.md` and this file together, and re-run the spine through `agent-approval-grant` if the change is substantive.

## Pagination

Not applicable — single-shot request/response, no lists to paginate.
