Implementation-level detail captured during PRD discovery that belongs downstream (architecture) rather than in the PRD body.

## Tech Stack Direction

- Vanilla HTML/CSS/JS — no front-end framework (React/Vue/etc.).
- Plain CSS — no Tailwind or UI kit.
- Rationale: user requested "basic" during Fast-path discovery, consistent with the brief's 1-2 hour build target and single-front-end-session constraint.
- Relevant to: `bmad-architecture` (data shape / app spine) and implementation stories.
