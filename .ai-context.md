- Governing documents: PRD `_bmad-output/planning-artifacts/prds/prd-BMAD-2026-07-27/prd.md` (approved v1); Architecture Spine `_bmad-output/planning-artifacts/architecture/architecture-BMAD-2026-07-29/ARCHITECTURE-SPINE.md` (approved v1); Epics/Stories `_bmad-output/planning-artifacts/epics.md`

```

  index.html      # single-screen layout

```

## Testing Convention

`node --test` (built-in runner, already wired via `npm test`) — no other test framework. No coverage threshold has been set by the PRD or Architecture; write tests that exercise each Acceptance Criterion in the relevant story.

## Global Do-Not-Do Rules (Always Enforced)

- Do NOT introduce a web framework (Express, Fastify, etc.) — Node core `http` only (Architecture AD-1).
- Do NOT read the LLM API key anywhere except `process.env.IDEA_LLM_API_KEY` inside `lib/ideaService.js` (AD-2).
- Do NOT add a database, session store, or any server-side persistence — all state is client-side and session-only (AD-3).
- Do NOT cache or memoize `generateIdeas` responses — every call must be a genuinely fresh LLM call (AD-6, PRD counter-metric SM-C1).
- Do NOT wire the in-repo `PromptGateway/` service into this app's runtime — it is unrelated tooling for a separate Claude Code prompt-hygiene hook (Architecture Spine, Deferred).
- Do NOT introduce a new third-party dependency without updating `.ai-context-dependencies.md` first.
- Do NOT modify files outside the scope of the current story's approved plan.
- Do NOT architect deployment/CI/infra — explicitly deferred and out of scope for this MVP (Architecture Spine, Deferred).
